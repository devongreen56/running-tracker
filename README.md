# 러닝 트래커 (Expo 앱)

브라우저가 아닌 진짜 네이티브 앱으로 실행하기 위한 React Native(Expo) 프로젝트예요.
실제 GPS(expo-location)로 거리를 측정하고, 프로필 체중을 기반으로 칼로리를 계산해요.

## 0. 준비물
- 컴퓨터에 Node.js 설치 (https://nodejs.org, LTS 버전)
- 폰에 **Expo Go** 앱 설치 (App Store / Play Store에서 "Expo Go" 검색)

## 1. 프로젝트 실행 (제일 먼저 이걸로 확인하세요)
압축을 풀고 터미널(명령 프롬프트)에서 이 폴더로 이동한 뒤:

```
npm install
npx expo install --fix
```

`npx expo install --fix`는 지금 설치된 Expo Go 앱 버전에 맞춰 모든 패키지 버전을 자동으로 정확히 맞춰주는 명령어예요.
Expo SDK는 몇 달마다 새 버전이 나오기 때문에, 버전을 직접 하나하나 맞추는 것보다 이 명령어를 쓰는 게 훨씬 안전해요.

그다음:
```
npx expo start
```

터미널에 QR코드가 뜨면:
- **안드로이드**: Expo Go 앱을 열고 "Scan QR Code"로 스캔
- **아이폰**: 기본 카메라 앱으로 QR코드를 스캔하면 Expo Go로 연결

몇 초 후 폰에서 앱이 실행돼요. 이 상태는 이미 브라우저 주소창이 전혀 없는 **진짜 네이티브 앱 실행 화면**이에요.
(단, Expo Go 안에서 도는 상태라 앱 아이콘은 아직 Expo Go로 보여요.)

## 2. 진짜 설치 파일(apk) 만들기 — Expo Go 없이 독립 실행

```
npm install -g eas-cli
eas login
```
(Expo 계정이 없으면 로그인 화면에서 무료로 바로 가입돼요.)

```
eas build --platform android --profile preview
```

- 처음 실행하면 앱 아이콘/패키지 이름 관련 몇 가지 질문에 Enter로 기본값을 진행하면 돼요.
- 빌드는 Expo 클라우드 서버에서 진행돼요 (컴퓨터 사양과 무관, 보통 5~15분 소요).
- 끝나면 터미널에 `https://expo.dev/artifacts/...` 같은 apk 다운로드 링크가 떠요. 그 링크를 폰 브라우저로 열어서 다운로드하면 바로 설치 파일이 받아져요.
- 폰에서 설치할 때 "출처를 알 수 없는 앱" 허용 팝업이 뜰 수 있어요 → 허용하면 설치 진행돼요.

이 apk는 Expo Go 앱 없이 독립적으로 실행되고, 실제 앱 아이콘(초록 배경 러닝 코스 아이콘)으로 홈 화면에 설치돼요.

아이폰(.ipa)은 애플 개발자 계정(연 $99)이 있어야 실제 기기 설치가 가능해요:
```
eas build --platform ios --profile preview
```
계정이 없다면 우선 1번 Expo Go 방식으로 테스트하면 돼요.

## 거리·시간이 실제보다 적게 측정되는 문제 (수정됨)
이전 버전은 화면이 꺼지거나 앱이 백그라운드로 가면 GPS와 타이머가 멈춰서 실제보다 거리가 적게 잡히는 문제가 있었어요.
지금 버전은 화면이 꺼져 있어도 계속 기록되도록 백그라운드 위치 추적을 켰어요. 러닝을 시작하면:
- 위치 권한을 두 번 물어봐요: 먼저 "앱 사용 중" 허용 → 그다음 "항상 허용"(백그라운드) 허용. 둘 다 허용해야 화면이 꺼져도 계속 측정돼요.
- 안드로이드는 상태 표시줄에 "러닝 측정 중" 알림이 계속 떠 있어요 — 이건 정상이고, 이게 있어야 화면이 꺼져도 시스템이 앱을 안 죽여요.
- 이 기능은 `eas build`로 만든 실제 앱(apk)에서만 정상 동작해요. Expo Go 안에서는 백그라운드 추적이 제한적이라 화면을 켜둔 상태로 테스트해주세요.

**중요:** app.json에 새 권한이 추가됐기 때문에, 기존에 만든 apk가 아니라 **다시 빌드**해야 반영돼요:
```
eas build --platform android --profile preview
```

## 기록에서 지도로 경로 보기 (새 기능)
"기록" 탭에서 러닝을 탭하면 실제로 뛴 경로가 지도 위에 선으로 표시돼요. 이 기능을 쓰려면 안드로이드는 **구글 지도 API 키**가 하나 필요해요 (iOS는 애플 지도를 기본으로 써서 별도 키가 필요 없어요).

### 구글 지도 API 키 발급 (무료)
1. https://console.cloud.google.com 접속 후 구글 계정으로 로그인
2. 상단에서 새 프로젝트 생성 (아무 이름이나, 예: `running-tracker`)
3. 왼쪽 메뉴 → **API 및 서비스 → 라이브러리** → "Maps SDK for Android" 검색 → **사용 설정**
4. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키** 클릭하면 키가 생성돼요 (`AIza...`로 시작하는 문자열)
5. 결제 계정 등록을 요구할 수 있는데, 개인 앱 수준 사용량은 무료 한도 안에 들어가서 실제 과금은 거의 안 돼요

발급받은 키를 `app.json`에서 이 부분에 붙여넣어주세요:
```
"config": {
  "googleMaps": {
    "apiKey": "여기에_구글맵_API_키_입력"
  }
}
```

키를 넣지 않으면 안드로이드에서 지도가 빈 화면(회색)으로 나올 수 있어요. 넣은 뒤 다시 빌드해주세요:
```
eas build --platform android --profile preview
```

## 걸음 수 기능 추가
app.json에 걸음 수 측정 권한(NSMotionUsageDescription, ACTIVITY_RECOGNITION)이 새로 추가됐기 때문에,
반드시 **다시 빌드**해야 반영돼요:
```
eas build --platform android --profile preview
```
앱을 처음 열면 동작 및 피트니스 활동 권한을 물어봐요 — 허용해야 걸음 수가 표시돼요.
안드로이드 기기에 따라 앱이 꺼져 있는 동안의 걸음까지는 못 세고, 앱을 켠 이후부터의 걸음만 정확히 세는 경우가 있어요 (기기 하드웨어 걸음 센서 지원 여부에 따라 달라요).

## 3. app.json에서 바꿔야 할 것
`com.yourname.runningtracker` 부분을 원하는 고유 패키지 이름으로 바꿔주세요 (예: `com.jisoo.runtracker`).
이름과 아이콘은 이미 채워져 있어요.

## 이번 수정 사항 (자동저장 / 거리 정확도 / 지도 전체화면)

**1. 앱이 강제 종료돼도 운동 기록 보존**
러닝 중 5초마다 진행 상황(거리, 경로, 시간)을 폰에 저장해둬요. 만약 러닝 도중 앱을 최근 실행 목록에서 지우거나 비정상 종료되면, 다음에 앱을 열었을 때 홈 화면에서 자동으로 감지해서 "이전 운동이 자동 저장됐어요" 알림과 함께 기록에 추가해줘요. (최대 5초 분량의 마지막 구간만 유실될 수 있어요.)

**2. 거리 측정 정확도 개선**
GPS 신호가 흔들릴 때 생기는 잔떨림과 튐을 걸러내도록 필터를 추가했어요:
- 위치 정확도가 나쁜(25m 이상 오차) 신호는 무시
- 3m 미만의 미세한 흔들림은 거리로 안 더함
- 사람이 낼 수 없는 속도(시속 28.8km 초과)로 튄 지점은 GPS 오류로 판단해 무시

이전보다 거리가 더 짧고 정확하게 나올 거예요.

**3. 지도 탭하면 전체화면**
"기록" → 러닝 선택 → 지도를 탭하면 전체화면 지도로 확대돼서 보여요. 왼쪽 위 ✕ 버튼으로 닫을 수 있어요.

**주의:** 위 세 가지 모두 코드/네이티브 설정 변경이 포함되어 있어서 반드시 재빌드해야 반영돼요:
```
npm install
npx expo install --fix
eas build --platform android --profile preview
```

## 지도가 계속 안 보이는 문제 (별개 이슈)
코드 수정과 무관하게, 구글 지도 타일 자체가 안 뜨는 건 API 키 설정 쪽 문제예요. Cloud Console에서:
- API 키의 "애플리케이션 제한사항"이 "없음"인지
- "API 제한사항"에 Maps SDK for Android가 포함되어 있는지(또는 "제한 안 함")
- 결제 계정이 정상 연결되어 있는지
다시 한번 확인해주세요. 이 부분은 앱 코드가 아니라 Google Cloud 프로젝트 설정 문제예요.

## 새 기능: 기록 초기화 / 삭제 / 지도 줄자

**기록 초기화** — "기록" 탭 오른쪽 위 "초기화" 버튼 → 이번 주 / 이번 달 / 전체 중 선택 → 확인창에서 한 번 더 확인 후 삭제돼요.

**개별 기록 삭제** — 각 러닝 항목 오른쪽에 "삭제" 버튼이 생겼어요. 눌러서 확인하면 그 기록만 삭제돼요.

**지도 줄자(거리 측정)** — 기록 상세 → 지도 탭해서 전체화면 진입 → 오른쪽 위 "📏 거리 측정" 버튼 → 지도를 탭해서 지점을 여러 개 찍으면 그 지점들을 이은 총 거리를 계산해줘요 (실제 뛴 경로와는 별개로, 지도 위 임의의 두 지점 사이 거리를 재는 용도예요, 예: "저기서 저기까지 몇 km인지 궁금할 때").

이 기능들도 코드 변경이라 재빌드 필요해요:
```
eas build --platform android --profile preview
```

## 새 기능: 지도 크래시 수정 / 러닝 중 사진 촬영

**지도 측정 시 앱이 죽던 문제 수정**
"기록 상세" 화면의 작은 지도가 뒤에 계속 떠 있는 상태로 전체화면 지도가 하나 더 열려서, 구글 지도 뷰가 두 개 동시에 활성화되며 생긴 문제였어요. 전체화면 지도로 넘어갈 때 뒤에 있던 작은 지도가 자동으로 내려가도록 고쳤고, 측정 기능에서 크래시 위험이 있던 점선 스타일도 안전한 실선으로 바꿨어요.

**러닝 중 사진 촬영 → 지도에 위치 표시**
러닝 화면에 "📷 사진 찍기" 버튼이 추가됐어요. 사진을 찍으면 그 순간의 GPS 위치와 함께 저장되고:
- 기록 상세 화면의 지도에 사진 위치가 작은 썸네일 마커로 표시돼요
- 화면 아래쪽에 찍은 사진들을 가로로 넘겨보는 스트립도 추가됐어요
- 전체화면 지도에서도 사진 마커를 탭하면 크게 볼 수 있어요

사진 파일은 앱 내부 저장공간에 복사해서 보관하기 때문에, 갤러리에서 원본 사진을 지워도 앱 안의 사진은 남아있어요.

**필요한 패키지가 추가됐으니 재빌드 전에 꼭 재설치해주세요:**
```
npm install
npx expo install --fix
eas build --platform android --profile preview
```

**주의:** `app.json`에 카메라 권한 설정이 새로 추가됐어요. 혹시 기존 `app.json`에 넣어두신 구글 지도 API 키가 있다면, 이번에 받은 파일에는 그 키가 비어있는 상태(`"여기에_구글맵_API_키_입력"`)이니 **다시 입력해주셔야 해요.**

## 사진 저장 실패 문제 수정
Expo SDK 54부터 `expo-file-system` 라이브러리의 기본 동작 방식이 바뀌면서, 사진을 앱 저장공간에 복사하는 부분(`documentDirectory`, `copyAsync`)이 새 버전에서는 그대로 작동하지 않았어요. `expo-file-system/legacy` 경로로 가져오도록 수정해서 해결했어요. 재빌드하면 정상적으로 사진이 저장돼요.

## 새 기능: 사진 크게 보기 / 이전·다음 기록 이동
- 기록 상세 화면에서 사진 스트립의 사진을 탭하면 전체화면으로 크게 볼 수 있어요.
- 기록 상세 화면 아래쪽에 "‹ 이전 기록" / "다음 기록 ›" 버튼이 생겼어요. "기록" 탭 목록 순서 기준으로 위/아래 기록으로 바로 이동해요 (목록으로 안 돌아가도 됨). 맨 처음/마지막 기록에서는 버튼이 비활성화돼요.

## 새 기능: 통계/캘린더, 날씨, 공유 카드

**월별·연간 통계 + 캘린더 (새 "통계" 탭)**
- 달력에 러닝한 날이 초록 동그라미로 표시되고, 그 날 뛴 거리도 작게 같이 보여요
- 좌우 화살표로 월 이동 가능
- "이번 달 vs 지난달" 막대그래프로 거리 비교, 횟수·시간·칼로리도 같이 비교
- 연간 누적 거리·횟수 요약

**날씨 표시 (홈 화면)**
- 위치 기반으로 현재 날씨·기온을 홈 화면 오른쪽 위에 작은 카드로 보여줘요
- 무료 오픈소스 날씨 서비스(Open-Meteo)를 사용해서 별도 API 키나 결제 등록이 필요 없어요 (구글 지도와 다르게 바로 작동해요)

**공유 카드 (완료 요약 화면)**
- 러닝 완료 화면에 "📤 공유 카드로 내보내기" 버튼이 생겼어요
- 누르면 통계 카드를 이미지로 만들어서 카카오톡/인스타그램 등으로 바로 공유할 수 있는 공유창이 떠요

새 패키지가 추가됐으니 재빌드 전에 설치해주세요:
```
npm install
npx expo install --fix
eas build --platform android --profile preview
```

## 새 기능: 통계 캘린더에서 날짜 선택 → 그 날 기록 보기
"통계" 탭 달력에서 날짜를 탭하면 그 날짜 아래에 그 날의 러닝 기록(시간, 거리, 칼로리)이 나와요. 기록을 탭하면 "기록" 탭의 상세(지도) 화면으로 바로 이동해요. 기록이 없는 날을 탭하면 "이 날은 러닝 기록이 없어요"라고 표시돼요.

## 버전/빌드 날짜 표시
"프로필" 탭 맨 아래에 앱 버전과 빌드 날짜가 작게 표시돼요 (예: "버전 1.1.0 · 2026-10-01 빌드").

버전은 `app.json`의 `version`과 `src/buildInfo.js`의 `APP_VERSION`에 각각 들어있어요 — 다음에 기능을 추가하고 새로 빌드할 때는 이 두 값과 `BUILD_DATE`를 같이 업데이트해주시면 화면에 정확한 정보가 표시돼요. (자동으로 빌드 시점을 기록하는 방식이 아니라, 수동으로 맞춰주는 방식이에요.)

## 절전 모드 대응 (v1.2.0)
- 러닝 중 위치 추적이 시스템에 의해 중단되면 1초 틱에서 감지해 자동 재시작
- 앱이 다시 앞으로 오면 거리/시간 즉시 갱신
- 첫 러닝 시 배터리 최적화 제외 안내, 러닝 화면 '절전 모드 설정' 버튼, 프로필에 '절전 모드 대응' 메뉴
- '화면 켜짐 유지' 토글 (켜면 화면이 꺼지지 않아 가장 안정적, 배터리는 더 소모)
- 삼성 폰: 설정 → 앱 → 운동 → 배터리 → '제한 없음'
- 새 패키지: expo-intent-launcher, expo-keep-awake, expo-constants → npm install 필요

## 거리 과소 계산 수정 (v1.2.1)
- 3m 미만 이동을 버리면서 기준점을 옮기던 버그 수정 (달릴 때 1초 간격 ~2.5m 이동이 전부 버려졌음). 이제 기준점에서 3m 이상 벗어날 때만 반영.
- 신호 튐 이후 기준점이 영구히 막히던 버그 수정 (속도 기준으로만 판단, 기준 시각 유지).
- 정확도 허용치 25m → 40m.
